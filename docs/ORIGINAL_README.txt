작성: 2026-10-14

1. 실행
field_photo_voice_v2.html을 Chrome 또는 Edge로 엽니다.
이 파일은 로컬 동작 초안이며 공개 사이트나 클라우드와 연결되지 않았습니다.
현장 등록은 기존처럼 점검 시작 → 말하면서 촬영 → 점검 종료 흐름을 유지합니다.
CLOVA 음성인식, 동호수 음성 명령, 사진별 발화 연결은 아직 미연결입니다.
카메라·연속 녹음 테스트는 기기 및 브라우저 권한 확인이 필요합니다.
실제 현장용으로 사용하기 전에 HTTPS 배포 및 실제 휴대폰 검증이 필요합니다.

2. 추가된 기능
[내 등록]
- 표 / 사진 보기 전환, 검색, 실제·체험 구분
- 날짜·동호수·위치·공종 필터 (휴대폰에서는 필터 버튼으로 펼침)
- 위치·공종·지적 유형은 내용의 키워드 기반 자동 분류 초안
- 담당 업체는 기존 지적 내용에 그대로 유지, 촬영 시 추가 입력 없음
- 사진이나 내용을 열어 분류·비고를 수정하면 목록·엑셀·집계에 함께 반영
- 선택 항목이 있으면 현재 조회 범위의 선택 항목만 내보냄
- 선택이 없으면 현재 조회되는 항목 전체를 내보냄
- 현재 필터 밖의 선택 기록은 내보내지 않음

[사진 포함 엑셀]
실제 .xlsx 파일이며 두 개의 시트를 포함합니다.
등록목록: 날짜 / 동호수 / 위치 / 공종 / 내용 / 비고 / 해당사진
사진은 G열의 각 기록 행에 삽입되는 이미지 개체이며 외부 사진 링크가 아닙니다.
사진은 행 안에 맞춰 축소 삽입하고, 원본은 브라우저 기록·ZIP 백업에 유지됩니다.
집계: 내보낸 기록 기준 위치별·공종별·동호수별 건수와 비중
집계 건수는 COUNTIF 수식이며 목록의 값을 변경하면 재계산합니다.
집계 범주 목록은 내보낼 당시 기준입니다. 엑셀에서 새로운 범주를 추가했다면
앱에서 다시 내보내거나 집계 시트의 범주 행을 직접 추가하세요.
체험 기록과 자동 분류 확인 전 상태는 비고에 명시합니다.
표 제목·헤더 고정, 자동 필터, A4 가로 인쇄 설정을 포함합니다.
한 번에 최대 1,000건까지 지원합니다. 많은 사진은 날짜·위치별로 나눠 내보내세요.
엑셀 정렬·사진 동작은 사용 중인 Excel 버전에서 최종 확인하세요.
녹음 원본은 엑셀에 들어가지 않습니다. 녹음은 기록 백업에 포함됩니다.

[집계·분석]
기본값은 실제 기록만입니다. 체험 기록을 명시적으로 분리해 볼 수 있습니다.
등록 건수, 기록이 있는 동호수, 등록 최다 위치, 미분류 건수를 표시합니다.
위치·공종·유형 순위, 위치×공종 교차 집계, 동호수별 건수, 일자별 기록량을 제공합니다.
같은 위치·공종·유형이 3건 이상이면 다음 점검에서 먼저 확인할 후보로 표시합니다.
이는 규칙 기반 빈도 요약이며 AI 추론이나 실제 미래 예측이 아닙니다.

[AI 예측 시안]
‘욕실 타일 단차 하자 발생 가능성 높음’ 등의 문구는 UI 표시 예시입니다.
실제 모델과 연결되지 않았고, 확률이나 위험 점수를 계산하지 않습니다.
실제 예측에는 점검 대상 수, 정상 사례, 공정·시공 조건, 조치 결과,
중복·재점검 연결 정보, 향후 발생 여부를 확보하고 모델을 검증해야 합니다.
많이 등록된 위치가 실제 하자율이 높다는 뜻은 아닙니다.
현 버전은 사진 1건을 등록 1건으로 계산하며 중복 하자를 자동 제거하지 않습니다.

3. 예시 체험
내 등록 또는 집계·분석에서 ‘예시 36건으로 기능 체험’을 누릅니다.
욕실 12 / 거실 8 / 주방 6 / 안방 5 / 현관 3 / 작은방 2건의 예시가 추가됩니다.
예시는 실제 현장 자료가 아닙니다. 이미지도 촬영 사진이 아닌 체험용 삽화입니다.
이미 추가된 동일 ID의 예시는 다시 중복 추가되지 않습니다.
첨부 sample.xlsx도 같은 예시 36건으로 생성한 파일입니다.

4. 기존 기록 보관과 가져오기
기존 파일에서 ‘기록 백업’으로 ZIP을 받은 뒤 새 파일의 ‘기록 가져오기’에서 선택하세요.
v1과 v2 초안이 자체 생성한 ZIP 백업을 지원합니다. 임의 재압축 ZIP은 지원하지 않습니다.
사진·기록·세션·녹음 원본을 합치며 같은 ID의 기존 기록을 덮어쓰지 않습니다.
서로 다른 파일·브라우저·기기에서 같은 기록이 보이지 않을 수 있으므로 먼저 백업하세요.
브라우저 저장 데이터 삭제 시 원본이 사라질 수 있습니다.

5. 검증 범위
Chromium 렌더러에서 UI 동작, 필터·선택, 엑셀·ZIP 생성, 수정 반영,
체험 자료 분리, v1 백업→v2 가져오기, 기존 연속 촬영 체험 흐름을 확인했습니다.
본 환경은 URL 탐색·카메라 권한을 제한하므로 UI 시험에서만 별도의 메모리 저장소
어댑터를 사용했습니다. 이 테스트 어댑터는 배포 HTML에 포함되어 있지 않습니다.
배포 HTML에는 기존 native IndexedDB 저장 코드를 유지했습니다.
실제 디스크 재실행·휴대폰 카메라·마이크·백그라운드 동작은 현장 기기에서 검증해야 합니다.
사진 포함 엑셀의 ZIP/XML 구조, 헤더, 36개 이미지 연결과 집계 수식을 검증했습니다.
Microsoft Excel 데스크톱 앱에서 직접 여는 시험은 실시하지 않았습니다.
