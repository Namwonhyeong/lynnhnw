# 사용자 요구사항 — 개발 중 유지할 기준

## 1. 해결하려는 업무

기존에는 현장 사진 촬영과 종이 메모를 별도로 하고, 사무실에서 사진·설명을 다시 맞춰
엑셀/문서를 만든 뒤 작업자들에게 배분·공유했다. 이중 입력과 사후 정리를 줄이는 것이 목적이다.
한 세대에서 약 30~40건을 기록하므로 촬영마다 입력 항목이 늘어나는 설계를 피한다.

## 2. 최종 목표 흐름

```text
세대 진입 → 점검 시작 한 번
          → 동호수 음성 지정, 유지
          → 말하면서 촬영 버튼 한 번
          → 같은 화면에서 다음 사진 촬영 반복
          → 점검 종료
          → 등록 목록 조회 / 선택한 항목을 사진 포함 엑셀로 출력
```

최종 목표와 현재 구현을 혼동하지 않는다. 현재 체험 모드만 예시 설명이 자동으로 붙으며,
실제 촬영에는 음성인식·발화 연결이 아직 없다.

## 3. 입력 최소화 원칙

- 사진마다 녹음 시작·녹음 종료·등록 확정 버튼을 추가하지 않는다.
- 촬영 화면에서 담당 업체·공종·세부 위치를 필수 선택하게 만들지 않는다.
- 담당 업체는 지적 내용 안에서 함께 말한다. 업체 분류/배분은 목록에서 나중에 한다.
- 동호수는 세대가 바뀔 때만 변경하고, 동일 세대에서는 기본적으로 유지한다.
- 이전 기록에는 촬영 당시 동호수를 저장한다. 새 위치가 이전 사진까지 바꾸면 안 된다.
- 음성 변환이 늦어도 사진을 저장하고 다음 촬영을 진행할 수 있어야 한다.
- 변환이 애매한 기록만 모아 나중에 확인한다. 모든 기록에 즉시 확인을 강요하지 않는다.

## 4. 위치를 둘로 구분

| 항목 | 예 | 유지/입력 원칙 |
| --- | --- | --- |
| 동호수 | 101동 1203호 | 음성으로 지정 후 다음 사진에도 유지 |
| 세대 내 위치 | 거실, 안방, 욕실 | 각 사진의 설명에서 파악 |

권장 위치 명령 예시는 `위치 변경, 101동 1204호`다.
이는 설계 제안이며 현재 실제 인식 명령은 아니다.
업체명·숫자·동호수는 근거 없이 교정하지 않는다.

## 5. 등록 목록과 엑셀

요청된 엑셀 열 순서는 고정한다.

**날짜 / 동호수 / 위치 / 공종 / 내용 / 비고 / 해당사진**

사진은 이미지로 포함한다. 원본 설명 안에 있는 담당 업체명은 삭제하지 않는다.
선택이 있으면 조회 범위 내 선택 기록만, 선택이 없으면 현재 필터의 전체 기록을 내보낸다.
코드의 기본 엑셀 구조는 `등록목록`과 `집계` 두 시트다.
향후 여러 사진을 한 지적에 묶게 되면 집계 단위와 엑셀 행 구조를 다시 합의해야 한다.

## 6. 집계와 AI

위치별 최다 등록, 공종·유형·동호수별 건수, 날짜 추이, 위치×공종 조합을 본다.
현재는 사진 등록 1건=집계 1건이다. 동일 하자 재촬영/재점검 자동 병합은 없다.

정상 점검 수나 전체 점검 대상이 없으면 발생률을 계산했다고 표시하지 않는다.
예를 들어 욕실 지적이 많다는 사실만으로 욕실의 하자 발생률이 높다고 결론 내리지 않는다.

AI의 미래 목표는 `특정 조건에서 ○○하자 발생 가능성이 높음` 같은 안내다.
지금은 화면 시안만 요구된 단계이므로 실제 AI 결과처럼 제시하지 않는다.
실제·체험 기록은 집계/학습/평가 전체에서 분리한다.

## 7. 음성 서비스 방향

우선 검토 대상은 NAVER Cloud CLOVA Speech다. 건설 용어·현장 업체명 인식이 중요하다.
최종 공급자와 방식은 현장 녹음의 정확도, 연결 지연, 사진 연결 오류, 비용을 비교해 확정한다.
현재 키워드 규칙은 받아쓴 텍스트를 분류하는 기능일 뿐, 음성을 잘 듣게 만드는 사전이 아니다.
현장 용어 사전과 텍스트 분류 규칙은 별개로 관리해야 한다.

## 8. 아직 정해지지 않은 운영 항목

배포 계정, 서버/DB 종류, 로그인 방식, 현장 권한, 보관 기간, 공유 범위, 음성 비용 한도,
여러 사진을 같은 지적에 연결하는 정책, 조치 완료/재점검 절차는 별도 합의 대상이다.
이번 코드에 이러한 운영 정책이 이미 들어 있다고 가정하지 않는다.

## 9. 현장 인수 시험 기준 제안

한 세대 30~40건을 실제 휴대폰으로 점검하면서 현장 입력 시간뿐 아니라
사무실에서 공유 가능한 목록을 완성할 때까지의 총시간을 비교한다.
건설 용어·업체명·동호수 오류, 사진-설명 오연결, 저장 누락, 재입력 횟수를 따로 센다.
말을 사진 전/도중/후에 하는 경우, 두 지적을 연달아 말하는 경우,
무음 사진, 위치 변경 직전/직후, 전화/화면 잠금, 통신 끊김을 포함한다.
절감 시간이나 정확도 수치는 실제 측정 전에는 목표/가정으로만 표시한다.
