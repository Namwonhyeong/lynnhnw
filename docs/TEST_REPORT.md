# 패키지 검증 결과

검증일: 2026-10-16. 대상: 대화에 제공된 현장노트 v2를 분리한 개발 소스와 빌드 파일.
앱 기능을 새로 완성한 검증이 아니라 **파일 분리 이후 기존 화면 로직의 점검**이다.

## 1. 정적·빌드·서버 확인

- 원본 v2 HTML 바이트 동일성 확인
- 8개 JavaScript 파일 문법 검사 통과
- 자유발화 동·호수 파서 단위 테스트 통과 (`node tests/speech_test.js`)
- 개발 서버·빌드·테스트 Python 문법 검사 통과
- 단일 HTML 빌드 성공; 외부 CSS/JS 참조와 테스트 저장소 코드 미포함 확인
- Python 로컬 서버 HTTP 200 및 CSS/JS 자산 8개 응답 확인 (브라우저 탐색 시험과 별개)

## 2. UI·엑셀·백업 로직 확인

이 환경의 관리형 Chromium에서는 로컬 HTTP 페이지 탐색이
`net::ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되었다.
따라서 `tests/smoke_test.py`의 네이티브 IndexedDB·미디어 전체 시험은 실행을 완료하지 못했다.
이 오류를 앱 자체의 저장소 오류로 판정하지 않으며, 제한을 해제하거나 우회하지 않았다.

대신 **로컬 문서를 직접 렌더링하고 독립 메모리 저장소 어댑터를 주입한 UI 시험**을 수행했다.
`tests/ui_harness.py`와 `tests/memory_store_adapter.js`가 해당 테스트 전용 코드다.
이 어댑터는 `src`와 `dist`에 포함되지 않고 실제 앱은 원래 IndexedDB 코드를 유지한다.

| 확인 항목 | 결과 | 범위 |
| --- | --- | --- |
| 분리 소스 화면 초기화 | 통과 | 로컬 HTML 렌더링 + 메모리 테스트 저장소; 네이티브 저장 검증 아님 |
| 체험 36건 생성·중복 방지 | 통과 | 테스트용 메모리 저장소에서 확인 |
| 집계·규칙 요약·실제/체험 분리 | 통과 | 욕실 12건; 반복 단차 8건; 실제 기록 0건 분리 |
| 사진 포함 엑셀 36건 | 통과 | 7열 순서, 2시트, 36개 이미지, XML·캐시·수식 구조 |
| 조회 필터·선택 내보내기 | 통과 | 욕실 12건 중 선택 1건만 사진 포함 출력 |

| ZIP 백업·빈 테스트 저장소로 복원·중복 방지 | 통과 | 테스트용 메모리 저장소에서 확인 |
| 체험 연속 촬영·위치 유지·변경 | 통과 | 별도 등록 버튼 없이 3건 생성, 이전 기록 위치 불변 |

| 단일 HTML 빌드 산출물 UI | 통과 | 동일 테스트 저장소 어댑터로 화면·예시 생성 확인 |
| 시험 중 처리되지 않은 JS 오류 없음 | 통과 | 테스트용 메모리 저장소에서 확인 |

세부 결과는 `UI_TEST_RESULTS.json`에 있다. 테스트 중 생성한 Excel은 ZIP/XML로
헤더·행 수·이미지 수·수식/캐시값을 확인했다. Excel 데스크톱 앱으로 직접 열어본 시험은 아니다.
화면은 Chromium 1440px와 390px 폭에서 렌더링해 확인했다.

## 3. 이번에 검증하지 못한 것

- 실제 브라우저의 네이티브 IndexedDB 디스크 보존·새로고침·재실행 유지.
- 실제 휴대폰/태블릿 카메라·마이크, 가상 장치 녹음 전체 시험, 장시간 연속 점검.
- Windows에서 BAT를 더블클릭해 서버를 실행하는 실제 운영체제 시험.
- 현장 소음에서의 음성 정확도, 발화-사진 연결, 동호수 음성 명령.
- 실제 Excel에서의 이미지 정렬/행 높이/인쇄 호환성.
- 수백~수천 장의 성능, 용량 초과, 네트워크 단절과 업로드 복구.
- 로그인·권한·서버/클라우드·AI 예측. 이 기능들은 아직 구현되어 있지 않음.

## 4. 인수 후 재현 순서

`tests/smoke_test.py`를 개발자 컴퓨터에서 먼저 실행해 네이티브 저장소/가상 장치 동작을
확인한다. 그다음 실제 휴대폰의 HTTPS 환경에서 세대당 30~40건 연속 점검을 시험한다.
브라우저에서 생성한 엑셀은 작업자가 사용하는 Excel에서 열어 확인한다.

현재 코드에 문법 검사와 UI 시험이 있다는 이유로 상용 운영/보안/현장 검증이 완료됐다고
표시해서는 안 된다. `README.md`의 기능 상태 구분을 그대로 유지한다.
